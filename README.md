# Voyager 3D Space Mission Simulator Web Application

This is a web application that simulates the missions of the Voyager 1 and Voyager 2 spacecraft. It uses Three.js and React Three Fiber to create a 3D visualization of the solar system and the paths of the two spacecraft.

## Credits & Data Sources

- **Mission Dataset & Gaia Sky Integration:** Toni Sagristà (`tsagrista@ari.uni-heidelberg.de`), Astronomisches Rechen-Institut (ARI), Zentrum für Astronomie der Universität Heidelberg.
- **Voyager Trajectory Data:** Originally sourced from [Celestia Motherlode](http://www.celestiamotherlode.net/addon/addon_355.html) and interpolated for Gaia Sky.
- **Spacecraft 3D Models:** NASA Visualization Technology Applications and Development (VTAD) ([NASA Voyager 3D Model](https://science.nasa.gov/resource/voyager-3d-model/)).
- **Mission Information & Imagery:** NASA / Jet Propulsion Laboratory ([NASA Voyager Mission](https://voyager.jpl.nasa.gov/)).
